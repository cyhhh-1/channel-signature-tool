# 安装版使用说明

## 安装与资料

双击下载到的 `通道生效签名短链程序_安装版_*.exe` 安装（文件名中包含产品版本和发布日期）。程序随安装包提供 Python 运行环境、模板、地区库和初始主码号资料；电脑不需要单独安装 Python，也不需要把 Excel 资料放在程序旁边。

首次运行时，程序把初始主码号映射复制到当前用户的 `%LOCALAPPDATA%\通道生效签名短链程序\通道编号及对应主码号.xlsx`。之后点击窗口右上角“主码号管理”进行搜索、添加、修改或删除。一个主码号可以对应多个通道。初始表中非 8 位的旧记录会标为“需修正”，处理逻辑在修正前不会使用这些记录。修改只作用于当前电脑；重装或升级程序不会覆盖已有的本地资料。卸载程序也保留该目录，便于重新安装后继续使用。建议定期备份这个目录。

## 自家移动

选择“自家移动”后：

1. 在“关键信息表”选择或拖入本次报备表 `.xlsx`。
2. 在“总表文件夹”选择路径，或从文件管理器拖入包含最新移动签名总表的文件夹。
3. 点击“开始处理”。程序直接读取选定文件夹中的完整总表，不复制、不合并历史版本。

总表文件名继续使用 `8位主码号+省份+移动签名总表.xlsx` 或 `8位主码号-5G+省份+移动签名总表.xlsx`，例如 `10000010甘肃移动签名总表.xlsx`。关键信息表的已生效行仍须只有一个归属省；普通移动与 5G 仍按消息类型分流。选错文件夹、缺少所需总表或文件名不符时程序会提示。

## 子端口分配

参阅《子端口分配使用说明》。如某行只需行业号，在待分配表新增“分配类型”列并填“仅行业”；只需营销号则填“仅营销”。留空沿用两类同时分配。
