# 子端口分配使用说明

## 操作

1. 在程序中选择“子端口分配”，点击“下载分配模板”保存空白模板。
2. 填好模板后，“待分配表”选择本次需要填号的 Excel；“历史总表”选择最新一版总表。
3. 点击“开始分配”。程序在待分配表所在目录的 `生成结果` 文件夹生成两份新文件：已分配表和更新总表。原文件不改动。
4. 下次分配使用本次生成的**更新总表**。

## 表格与编号规则

- 待分配表只需一张工作表，表头的前 3 列依次是签名、行业、营销；允许表头上一行保留模板说明。
- 总表的表1提供“主码号、签名、四位签名编号”映射，表2“子端口记录”提供历史占用。签名编号只从总表表1读取；找不到签名时停止本批次分配并报错。
- 两个文件名都必须以同一个 8 位主码号开头，例如 `10000001分配.xlsx` 与 `10000001总表.xlsx`。程序还会核对总表表1的主码号。
- 下载的三列表模板中，行业和营销列都留空表示同时分配；在其中任意一列填“仅行业”或“仅营销”，则只分配对应类别。也可增加标题为“分配类型”的第 4 列或后续列填写这些选项。
- 只分配实际需要的类别，不占用另一类别的号码。完整号码 = 8 位主码号 + 4 位签名编号 + 3 位类型流水号；行业为 `701–999`，营销为 `001–699`。
- 从 `701`、`001` 起各自寻找未出现在历史总表的最小空号；两类独立回填。总表已有的号码始终视为已占用，包含已停用但仍保留记录的号码。
- 同一签名在不同主码号下可以使用不同的四位编号。不同主码号可以使用相同的后七位，完整子端口号不能重复。
- 每个主码号使用自己的分配表和总表，因此同一签名在不同主码号下可有不同编号。若待分配表另有“主码号”列，填写值也必须与文件名一致。
- 文件名主码号不一致、历史号码重复或某一类号码用完时，程序报错并且不生成本批次结果。

## 注意

总表必须保留所有已分配过的号码。删除历史记录会使该号码被识别为空缺并可能再次分配。此版本按每次手动选择总表工作，不提供跨电脑的同时分配锁定。
