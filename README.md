# 通道生效签名短链程序（脱敏代码框架）

Windows 桌面工具，用于把签名、链接和号码整理成固定的 Excel 导入模板，并支持自家移动、自家电信、子端口分配、拆分/合并表和签名一致性判定。

程序由 **C# WinForms/AntdUI 窗口** 和 **内嵌 Python 3.12 处理引擎** 组成。最终用户电脑不需要安装 Python；发布版会把 Python 运行时和模板打进安装包。

> **这是脱敏公开副本，不包含生产数据。**
> 仓库内的 `通道编号及对应主码号.xlsx` 是虚构示例（`19900001` / `10000001` 等），仅用于演示表结构。生产通道映射、客户名单、运营商回执、真实签名总表和业务交接文档均未上传。

## 功能

| 类别 | 功能 |
|---|---|
| 通道业务 | 自家移动、自家电信、子端口分配、生效短链、生效签名、混合表自动分流 |
| 数据工具 | 拆分/合并表、签名一致性判定、主码号管理 |

- 支持 `.xlsx`、`.csv`；生效签名额外支持 `.txt`。
- 结果不覆盖旧文件，同名时自动加序号。
- 异常行写入错误明细，不阻断其他数据。
- 全部处理在本机完成，不经过网络传输。

## 架构

```text
通道生效签名短链程序.exe
├─ C# WinForms/AntdUI 窗口
├─ C# 便携启动层（解压内嵌运行时、拼命令行参数）
└─ runtime_payload.zip
   ├─ Python 3.12 运行时 + openpyxl
   ├─ app.py（业务核心）
   └─ 模板 / 地区库 / 初始通道映射

- `源码/通道生效签名短链工具/通道生效签名短链工具源码.py`：业务规则唯一核心，包含 `process_file()` 统一入口和命令行入口。
- `源码/通道生效签名短链工具/便携启动器源码.cs`：正式窗口和便携启动层。
- `源码/tests/`：63 项自动测试。

cd 源码

```

当前 **63 项全部通过**。

## 构建安装包

仓库不包含体积较大的运行环境和打包工具。首次构建前，需要自行准备：

- `便携Python运行环境/`：Python 3.12 + openpyxl + et_xmlfile，含 `python.exe`
- `构建依赖/NSIS-3.12/`：含 `makensis.exe`
- Windows x64 + 系统自带 .NET Framework 4.x 的 `csc.exe`

然后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\生成安装包.ps1
```

构建会运行全部测试，生成 `输出\通道生效签名短链程序_安装版_<版本>_<日期>.exe` 和 `输出\构建结果.txt`。版本号只在 `版本.json` 中维护，运行环境缓存版本和映射种子由内容哈希自动生成。

详细说明见 [开发打包说明.md](开发打包说明.md) 和 [说明文档/Git与发版流程.md](说明文档/Git与发版流程.md)。

## 数据与安全

- 本仓库不含真实主码号、客户名称、号码、链接或运营商回执。
- 示例映射中的通道编号和主码号均为虚构，请勿用于生产。
- 程序不联网；主码号资料保存在 `%LOCALAPPDATA%\通道生效签名短链程序`。
- 仓库不包含数字签名证书，自行构建的安装包首次运行可能触发 Windows SmartScreen。
